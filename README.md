# Blue Vinyl

2026 FALL KAIST ID UXD project web prototype

Blue Vinyl - Auditory Trace for your own journey

## 시작하기

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. 배포용 파일은 `npm run build`로 만든 `dist`에 있습니다. `npm run preview`로 빌드를 확인할 수 있습니다.

## 사용 흐름

회고 화면의 점선 재생바는 날짜별로 나뉩니다. 큰 원은 각 날짜의 시작, 작은 점은 저장된 트랙이며 종이비행기는 실제 재생 위치를 표시합니다. 재생바를 누르거나 드래그해 트랙을 고르고, 목록에서 날짜별로 선택할 수 있습니다. 트랙이 끝나면 앱은 다음 트랙을 자동 재생하지 않습니다.

1. **+ Add New Album**을 누르면 빈 LP가 먼저 중앙에 나타납니다. 옆에서 날아온 재킷이 LP의 1/3을 감싸고, 재킷이 커져 위로 올라가면 그 아래에 정보 입력칸이 나옵니다. 입력 전 애니메이션은 총 5초입니다. 이름, 일정, 장소를 입력한 뒤 **Save**를 누르면 재킷이 작아져 다시 LP의 1/3을 감싼 상태로 잠시 머문 뒤 옆으로 빠집니다. 남은 빈 LP가 커지며 기록 화면으로 이어지는 저장 후 애니메이션은 총 3초입니다. 저장에 실패하면 정보 입력 화면을 유지합니다. 이후 LP 가운데의 **Enter information**으로 정보를 수정할 수 있습니다.
2. 빈 LP판을 누르면 녹화 화면이 열립니다. 왼쪽 아래 카메라를 켜거나 끕니다. 빨간 버튼을 누르는 동안 현장 소리가 노란 소리골로 새겨지고, 카메라가 켜져 있으면 놓는 순간 사진을 찍습니다. 사진을 찍은 뒤 오른쪽 위 **>**를 누르면 사진·노래·메모를 확인할 수 있습니다. 기록 날짜는 기기의 오늘 날짜로 자동 설정됩니다.
3. **PRESS INTO LP**로 새 기록을 담으면 LP 화면으로 돌아가고 소리골 한 줄이 새겨집니다. LP판을 누르면 다음 순간을 기록할 수 있습니다. LP 화면과 기록 화면 상단의 햄버거 버튼을 누르면 선반으로 바로 돌아갑니다. 사진 트랙은 자체 사진을 기본으로 쓰며, 각 트랙에 다른 사진을 지정할 수 있습니다.
4. LP 가운데를 누르고 **Finish my journey**를 고릅니다. 두 옵션은 110도 간격이며, 바로 누르거나 휠을 돌려 고를 수 있습니다. 종료를 확인하고 **Press!** 화면을 길게 누르면 사진이 LP 가운데에 들어갑니다. 배송 화면에서 위치 사용을 허용하면 가까운 도시와 거리에 따른 도착 예정일을 채웁니다. 두 값은 직접 수정할 수 있습니다. **OK**를 누르면 홈으로 돌아갑니다. 도착일이 되면 LP가 홈 선반에 표시됩니다.
5. 선반에서 LP를 선택한 뒤 레코드를 오른쪽으로 당겨 놓으면 열립니다. 홈의 턴테이블에는 도착한 LP 중 가장 최근에 완성한 LP가 놓입니다. Spotify 기본 플레이어 없이 톤암으로 휴대폰의 Spotify 앱에서 그 LP를 기록할 때 들었던 곡을 재생합니다. 저장된 Spotify 곡이 없으면 첫 현장음을 재생합니다. 톤암을 왼쪽으로 끌어 LP 위에 놓으면 재생되고, 오른쪽으로 빼면 정지합니다. 판을 누르면 앨범을 열 수 있습니다.
6. 받은 LP가 있을 때 홈에 종이비행기가 나타납니다. 비행기를 누르면 도착한 LP를 바로 재생하거나 내 선반에 저장하거나 버릴 수 있습니다.
7. 완성된 LP의 오른쪽 위 종이비행기를 눌러 여행지로 보내는 화면을 엽니다. **여행지로 보내기**를 누르면 지도에서 종이비행기가 날아갑니다. 이 화면에서 앨범 파일을 저장하거나, 웹에 올린 앱에서 작은 LP의 공유 링크를 만들 수 있습니다.
8. 재생 화면에서 톤암을 LP 위에 놓으면 현장음이 재생되고, 판 밖으로 빼면 정지합니다. 바깥쪽부터 기록 시간순으로 트랙이 놓이며, 톤암을 안으로 움직이면 나중 트랙이 선택됩니다. 가운데 사진도 선택한 순간의 사진으로 바뀝니다. 두 손가락을 벌리거나 **LP 확대**를 누르면 현장음을 포함한 기록이 핀으로 표시됩니다. 핀을 선택하면 **현장음 앞부분 / Spotify 곡 / 현장음 뒷부분**을 각각 골라 재생할 수 있습니다. **>|** 버튼으로 직접 다음 트랙으로 이동하며 자동 전환하지 않습니다. 현장음 앞부분 끝은 페이드아웃, 뒷부분 시작은 페이드인으로 재생합니다. Spotify 곡은 휴대폰의 Spotify 앱에서 재생하며, 앱의 톤암과 재생 버튼으로 조작합니다.

**LP 축소**를 누르거나 두 손가락을 오므리면 LP 옆에 다른 사진이 폴라로이드처럼 펼쳐집니다. 사진을 누르면 크게 볼 수 있으며, **LP 보기**로 원래 화면에 돌아옵니다. Spotify 플레이어의 재생·일시정지·종료 상태에 따라 톤암과 LP 회전도 함께 바뀝니다. 확대된 핀 회고 화면에서 두 손가락을 오므리면 원래 LP 화면으로 돌아옵니다. 사진은 LP와 함께 회전하며, 홈은 한 바퀴 60초, 회고 화면은 한 바퀴 180초입니다.

앨범과 미디어는 같은 브라우저의 IndexedDB에 저장됩니다. 녹음과 위치 확인에는 브라우저 권한이 필요합니다. 배송 거리 계산에 쓰는 좌표는 브라우저 안에서 계산합니다. 기록의 구체적인 위치명은 사용자가 동의한 뒤 현재 GPS 좌표를 komoot Photon에 보내 확인합니다. 기록에는 좌표 대신 위치명만 저장합니다. 배송 날짜는 앱 안에서 사용하는 거리 기반 예정일입니다. 지도와 도시 데이터는 [Natural Earth](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2)에서 가져왔습니다. 샘플 사진과 소리는 이 앱의 시연용으로 제작했습니다.

Spotify는 선반 하단의 설정 아이콘 → **Spotify 연결**로 로그인합니다. 기존 연결은 **Spotify 다시 연결**을 눌러 재생 제어 권한을 추가해야 합니다. 재생 중인 곡이 있으면 녹화 화면 위에 표시하고, 마이크를 켜기 직전 Spotify 곡 정보를 고정해 사진·현장음과 함께 저장합니다. 재생 중인 곡이 없으면 노래 카드는 표시하지 않습니다. 노래를 수동으로 추가하는 화면은 없습니다. Spotify 개발자 앱에 Redirect URI `https://prnagn.github.io/UXD-blue-vinyl-web/`를 등록해야 합니다. 로컬 확인용 Redirect URI는 `http://127.0.0.1:5173/`입니다. 필요하면 `VITE_SPOTIFY_CLIENT_ID`와 `VITE_SPOTIFY_REDIRECT_URI`로 연결 설정을 지정할 수 있습니다. 현재 곡 정보는 Spotify에서 읽고, 녹음과 소리골은 마이크 입력으로 만듭니다. 재생 제어에는 Spotify Premium이 필요합니다. 녹음 전에는 곡을 일시정지하고, 마이크와 오디오 세션을 닫은 뒤 같은 기기에서 재개합니다. 음량 제어를 지원하는 Spotify 기기에서만 앞뒤 페이드를 적용하며, 지원하지 않는 모바일 기기는 일시정지·재개로 동작합니다.

기록 확인 화면에서 사진을 좌우로 넘기면 맨 오른쪽에 **새로운 기록 녹화하기**가 있습니다. 사진을 길게 누른 뒤 좌우로 움직이면 사진·현장음·Spotify 곡 묶음의 순서를 바꿀 수 있습니다. 놓으면 확인 화면으로 돌아오고, **PRESS INTO LP**를 누르면 그 순서가 한 소리골에 저장됩니다. 설정 → **기록 초기화** → **Do you want format?** → **yes**는 이 앱의 IndexedDB를 삭제하며, **no**는 취소합니다.
